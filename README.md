# Lights-Out-Game

Tyler Sheehan and I recreated a classic game called Lights Out in C++. You can find and play the game here: https://www.logicgamesonline.com/lightsout/. 
The game is a 5x5 grid, where there is a random variation of lights on, and when you click on one, it toggles that square and all adjacent squares on or off depending on the previous state. 
The goal is to turn all the lights off. Tyler and I worked together to recreate this game, utilizing code provided by Lisa Dion for graphics as reference. Tyler worked mainly on setting up the grid and graphics,
while I worked out the intricacies of randomizing the lights, adding a timer, adding a click counter, and we both worked together to implement the game logic. Overall this project was a satisfactory experience
in developing my skills on coding graphics and game logic with C++.
